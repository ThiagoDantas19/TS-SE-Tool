# Política de distribuição

O download oficial é a seção [GitHub Releases](https://github.com/ThiagoDantas19/TS-SE-Tool/releases). Espelhos devem apontar para este repositório e não podem alterar o arquivo.

Toda divulgação deve informar:

- projeto gratuito e de código aberto, fork da continuação comunitária;
- atribuição ao autor original LIPtoH e à continuação comunitária de Fabio;
- ETS2 **1.61** com save **97** como alvo validado; ATS não validado;
- obrigação de backup e uso por conta e risco;
- versão e SHA-256 exatos;
- GitHub Issues como canal técnico;
- ausência de vínculo com a SCS Software.

Não use paywall, cadastro obrigatório, encurtador, wrapper de instalação, DLCs da SCS ou conteúdo pago de mods.
